# Animalito

Página web estática sobre animales vertebrados, desarrollada como trabajo práctico para la materia **Lenguajes III** de la **UCASAL**.

## Descripción

Animalito es una página informativa que presenta las cinco clases de animales vertebrados. El objetivo principal del trabajo fue implementar el componente **Carousel de Bootstrap**, complementado con un acordeón interactivo para mostrar el contenido.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5.3

## Componentes de Bootstrap utilizados

- **Carousel** — muestra imágenes de animales con controles de navegación e indicadores
- **Accordion** — despliega la descripción de cada clase de vertebrado
- **Navbar** — barra de navegación superior con el nombre del sitio
